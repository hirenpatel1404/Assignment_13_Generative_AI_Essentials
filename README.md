# Generative AI — Fine-Tuning GPT-2 on The Pile

Fine-tuning **GPT-2 (124M)** — a Generative Pre-trained Transformer — on a slice of **The Pile** public dataset to generate text, then comparing it against a modern instruction-tuned model (**Qwen2.5-1.5B-Instruct**). Built for the DAAI Lesson 13 (Generative AI Essentials) assignment.

---

## 📌 Overview

This project takes a real GPT model and fine-tunes it on public-domain text, showing the full generative-AI pipeline end to end. It also adds a bonus comparison against a current-generation model to highlight how far the technology has advanced.

The notebook covers:

1. **Environment setup** — install libraries, confirm GPU
2. **Load a slice of The Pile** — stream 2,000 text samples (no 800 GB download)
3. **Tokenization** — encode text with GPT-2's Byte-Pair Encoding
4. **Fine-tuning** — train GPT-2 for 1 epoch, with a training-loss graph
5. **Text generation** — produce text from seed prompts (temperature / top-k / top-p)
6. **Content-creation demo** — an article-intro generator
7. **Bonus** — load Qwen2.5-1.5B-Instruct and compare output quality

## 🚀 How to run

Developed in **Google Colab** with a **T4 GPU**.

1. Open [Google Colab](https://colab.research.google.com/) and upload `GenAI_Assignment_GPT2_Pile.ipynb`.
2. Set the runtime to GPU: **Runtime → Change runtime type → T4 GPU**.
3. Run the cells in order (**Runtime → Run all**).

**Timings on a free T4:** GPT-2 fine-tuning finishes in under a minute; loading Qwen for the bonus comparison downloads ~3 GB (1–3 min).

> **Library note:** this notebook uses a current version of `transformers`, so it uses the `datasets.map()` tokenization approach rather than the deprecated `TextDataset` class, and omits removed `TrainingArguments` options like `overwrite_output_dir`.

## 📊 Dataset

**The Pile** — a large, diverse, publicly available text dataset (~800 GB) covering web pages, books, academic papers, code, and more. Because the full dataset is far too large to download, the notebook **streams** it and collects 2,000 samples. It uses the `monology/pile-uncopyrighted` mirror on Hugging Face, since the original EleutherAI host is offline.

The Pile's mixed-source nature means the fine-tuned model learns a broad, general English style rather than one specific author's voice.

## ⚙️ Configuration

Key settings you can adjust in the notebook:

| Setting | Default | What it controls |
|---------|---------|------------------|
| `num_samples` | `2000` | How many Pile samples to stream |
| `block_size` | `128` | Tokens per training sample |
| `num_train_epochs` | `1` | Passes over the dataset |
| `per_device_train_batch_size` | `4` | Samples per training step |
| `temperature` | `0.8` | Output randomness (higher = more creative) |
| `top_k` / `top_p` | `50` / `0.95` | Sampling pool controls |

## 📈 Results

- The training loss fell from about **3.71** to the **3.27–3.3** range over 500 steps, showing the model learned from the data (see `training_loss.png`).
- The fine-tuned GPT-2 produces fluent English but occasionally **hallucinates** (invents facts) — an inherent trait of all generative models.
- The bonus **Qwen** comparison produces far more coherent, structured, and factual output, illustrating the impact of larger scale and instruction tuning.
